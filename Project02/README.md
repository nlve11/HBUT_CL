##洗衣机模糊推理系统 第二个课程实验

实验内容
本实验围绕“洗衣机模糊推理系统”展开，采用 Mamdani 模糊推理把两个 0～10 的精确输入（污渍程度、油污程度）转换为 0～60 分钟的洗涤时间建议。系统使用 NumPy 实现三角形与左右肩形隶属函数，把精确输入模糊化为“低、中、高”三个隶属度；用 9 条规则覆盖两个输入的全部组合，用最小值计算规则前件强度，用截断与最大值聚合规则输出，最后用离散重心法解模糊得到精确洗涤时间。
实验重点包括：理解精确集合边界与模糊集合连续过渡的区别；手工核对一个输入点在相邻隶属函数上的取值；说明规则前件为何使用 min、多条规则输出为何使用 max；用重心法把聚合曲线转换为洗涤时间；结合规则强度和结果图解释最终建议，而不是只报告一个数字。
